# M0 v2 → M1–M5 输入契约

所有模块从冻结 ZIP 的 manifest.json 开始，校验 schema_version=m0-2.0、来源哈希、coordinate_version 和 SfM 单位。不得把 draft、旧 M0 或历史 ReLaGS 语义输出当成当前人工确认先验。

| 模块 | 可读取的 M0 输入 | 本模块后续负责 |
|---|---|---|
| M1 工业空间约束高斯表示 | scene_bbox、T、确认的地面平面、scene_gaussian_indices、原始几何哈希 | 研究范围内表示 |
| M2 空间先验引导多视角对象建模 | object_catalog、设备 coarse_bbox、原图/相机/原始划分；可选单张 train reference | 自动多视角选择、SAM 批处理、关联、Superpoint/分组、精确实例 |
| M3 视觉—语言融合 | 基础双语名称和视觉描述；后续 M2 的对象结果 | CLIP 等编码与 ROFA/语义聚合 |
| M4 工业三维语义场景图 | 工业坐标参考；后续 M2/M3 结果 | 空间关系计算、图构建 |
| M5 语义与关系感知查询 | 后续对象语义与图 | 查询和关系推理 |

## 必须处理的约定

1. T 作用在原始 COLMAP 点的列齐次向量上；变换后与 bbox.center/size 比较。逆矩阵可用于相机投影。
2. scene indices 是原始 MWP PLY 的 vertex 行号，不是裁剪后连续编号。若下游再次裁剪，必须保留新旧映射。
3. 设备粗框只有空间约束，含地面/背景/邻接结构是允许的。**不得直接将框内全部高斯作为最终设备实例。**
4. 可选参考缺失是正常情况，不得使后续输入读取失败。若存在，检查 train、原图哈希、原生宽高、mask SHA 和 confirmed 状态。它仅为单视角身份提示。
5. 未标定实际尺度，禁止把 near 阈值或对象大小直接解释成米。M0 v2 不配置关系阈值。
6. 原图、相机、几何不复制进 ZIP；以工程根目录解析 manifest 的相对路径。跨机器迁移这些原始资源后必须校验哈希。
7. 本版不包含评价数据。后续独立评价方案不在 M0 v2 中预填。
