## 已发现并处理的问题

- 初始 RANSAC 最大近水平面可能是设备台面/顶部，直接作底面会截掉下方几何。改为稳健整体高度范围；最大面的法线只供方向候选，底面须人工确认。
- 三维拾取半径过小，远景可见点难以点击；按相机距离、视角、视窗高度换算约 5 个屏幕像素的容差。
- 切换对象、隐藏框、撤销跨页面、参考视角切换及编辑历史恢复的边界已补齐：隐藏独立保存且不取消确认；同一对象重复选择不丢草稿；参考草稿按实际已加载图像保存；恢复后保留操作审计。
- 新旧来源 diff 的比较须使用相同 --binary 选项，不能用不同输出格式的摘要判断源码改动。

## 当前限制与人工待办

- 本次交付是平台，不是完成后的人工先验数据集。需要用户重新确定 V2 场景框、地面、主通道方向，并选取第一批设备。
- 当前料架粗框和参考仍可能包含邻近相似料架；SAM 候选确实出现连带邻架的区域，模型高分不能消除身份歧义，需要人工调整或放弃可选参考。没有通过算法替换掩盖此问题。
- 点云浏览不等于原生 2DGS splatting：表面孔洞、遮挡、细杆或低密度结构应结合原始 RGB/真实渲染检查。未开发浏览器实时 2DGS 任意新视角渲染。
- 自动方向/范围是几何启发式候选，不是工业地面或通道识别结果。框底面未确认时不输出有效地面平面。
- 推荐视角依据投影面积、裁剪比例和画面偏移，未做后续 M2 的遮挡推理或多视角选择优化。单张参考可省略。
