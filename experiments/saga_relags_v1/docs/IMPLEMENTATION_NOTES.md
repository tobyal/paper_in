# SAGA + ReLaGS：实施记录

本方案独立于既有 ReLaGS、M1—M5 和 M2.1 实验。所有旧结果和 M0 均只读。最新已保存 M0 经数据库只读事务检查为 r29，包含33个对象、8类；源正式 review flag 仍为 draft，未擅自修改。已有混合观测与该快照、原生PLY哈希一致。

## 已核实的上游方法

- SAGA v2 固定到 `2d4c5d77c857c956d747e4775d3d72c4ec5dfe16`：[官方代码](https://github.com/Jumpat/SegAnyGAussians/tree/2d4c5d77c857c956d747e4775d3d72c4ec5dfe16)，[论文](https://arxiv.org/abs/2312.00860)。使用自动SAM掩膜、深度尺度估计、32维尺度门控亲和特征、官方对比损失、K=16局部平滑和提示特征相似度三维分割。
- ReLaGS：[论文](https://arxiv.org/html/2603.17605v1)、[SoM源码](https://github.com/dfki-av/ReLaGS/tree/main/scene_graph/som)。参考带编号图像、二维关系输出、对象ID映射和跨视角关系融合；本方案已知M0实例ID，省去层次群组发现和2D—3D群组匹配，不使用2DGS、THGS或GNN。
- B为已知类别的CLIP文本/图像表示；D为类别解析、实际关系筛选和已存实例投影。不会在查询时重新分割。

## A的数据与兼容处理

首批选10个对象，涉及物料车、装配夹具台、带黑色工件的夹具台、立式移动冷风机、多层料架，每类2个实例。输入74个观测：57个原始训练图像、17个已验证的完整场景虚拟渲染。44个原始留出图像不用于训练、提示或参数调整。

1. 完整原生3DGS复制为SAGA要求的`scene_point_cloud.ply`；不重训基础3DGS，原始行序作为Gaussian ID。
2. SAGA独立venv继承既有Torch 2.2/CUDA11.8库，只在新venv安装官方RGB、深度、32通道特征CUDA扩展。
3. 首次SAM提取失败：旧环境SAM为历史修改版，返回多层列表，与SAGA官方接口不一致。日志保留。新venv独立安装SAGA固定的官方SAM提交`6fdee8f2727f4506cfbbe553e23b895e27956588`，旧环境未修改。
4. 官方SAM入口的OpenCV BGR输入转为RGB；张量保存CPU，增加已有文件恢复。监督全部重新生成。
5. 官方相机缩放时原主点未同步缩放；适配为逐相机准确K，匹配既有原生渲染器的半像素约定。图像整数缩放与SAM尺寸统一。
6. 深度尺度仍使用官方全场景深度光栅化器，以及`norm(2*std(masked XYZ))`。纠正官方示例中的行列坐标混用，使用当前相机的真实焦距与主点；保存深度、尺度和投影误差检查。
7. 预计算完整原生高斯的精确欧氏K=16近邻，装入官方平滑缓存；与PyTorch3D采样距离对照。官方特征归一化、邻域均值和dropout不变。
8. M0框提示的少量新SAM参考掩膜作为额外监督/提示，明确记录为辅助先验。它们不是最终三维标签，也不是评测真值。自动掩膜另存原版。
9. 官方训练损失表达式、门控网络与优化器不变。额外记录真实损失和显存，保存亲和特征/尺度门控及可恢复训练状态。几何不在优化器中，关闭其无用梯度保存。

补丁和原文件分别保存在`docs/patches/`与`docs/upstream_original/`。完整命令、日志、耗时及GPU采样见`logs/<stage>/<attempt>/`。

## C的本地模型与边界

发现服务器本地Ollama服务，版本0.32.5，已安装具有vision能力的`qwen3.5:9b`。仅允许访问服务器回环地址`127.0.0.1:11434`；工业图像不发送外部API。模型列表快照保存在`inputs/ollama_models.json`。接口参考[官方生成API](https://docs.ollama.com/api/generate)。

左右/前后等关系由工业坐标的几何证据计算；SoM模型只负责具有实际视觉证据的关系。不要求不同完整设备之间必须存在包含/支撑关系；空输出或证据不足必须如实保留。
