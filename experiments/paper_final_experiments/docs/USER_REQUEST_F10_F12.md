# 四、F11：精细实体与空间关系机制的贡献分析

Contribution analysis of refined entity representation and spatial relation constraints.

## 4.2 图的研究目的

现有T03已经完成主要机制消融实验。

实际结果表明：

- 精细实体表达能够提高Precision，但同时存在一定Recall损失。

1. 精细实体表达在不同工业对象中的实际收益与局限。
2. 空间关系约束对相似设备检索的改善。
3. 两种机制在Precision与Recall上的不同作用。

Delta IoU(entity) = IoU(Ours) − IoU(Box-based)

因此，该差值反映在相同设备身份及关系条件下，精细实例表达对最终检索结果的影响。

### 图表形式

采用以0为基准的正负柱状图。

横轴为23条有效查询，按原始查询顺序排列。

纵轴为：

`ΔIoU (pp)`

正值表示精细实例提取带来改善，负值表示精细提取造成一定损失。

建议使用两种清晰且色盲友好的颜色区分正负变化。

# 六、三张数据图的统一绘制要求

## 6.1 整体风格

延续现有F04—F09的论文图片风格。

参考高质量计算机视觉、工业信息学及工程应用论文的数据图表达方式。

要求：

- 白色背景。
- 简洁的坐标轴和图例。
- 统一字体、字号及线宽。
- 统一英文术语。
- 清晰的子图编号。
- 适当留白。
- 色彩具有明确的数据表达意义。
- 图面在正式论文缩放后仍然清晰可读。

重点体现数据之间的差异、变化及分布，而不是通过复杂视觉装饰增加图表内容。

## 6.2 色彩设计

F10中不同方法采用固定颜色，并与其他涉及这些方法的数据标记保持一致。

Ours可以采用较为突出的深蓝色或其他明确主色。

F11中使用一致的正负变化配色，两个差值子图共用颜色含义和零基准线。

F12中固定三个阶段的颜色：

- 类别候选。
- 关系匹配目标。
- 可用精细实例。

颜色应兼顾色盲可读性及灰度打印效果。

## 6.3 数据统计要求

所有数值直接从真实实验文件计算生成。

明确处理：

- 有效查询与未评价查询。
- 真实零值。
- 百分比与百分点。
- 查询级平均方式。
- 累计候选次数与独立设备数量。
- 主消融配置与不同可用性条件下的补充配置。

F10、F11和F12中的实际统计结论以读取并重新计算的数据为准。

由于部分查询可能对应相同设备和评价视角，这些图用于描述当前测试集合中的实际性能分布，不进一步开展独立样本假设下的显著性检验。

## 6.4 图片尺寸及输出

参考现有实验图的双栏宽度设计，建议宽度约170—180 mm。

数据图优先采用矢量绘图。

每张图保存：

- 高分辨率PNG，建议450 dpi。
- SVG。
- PDF。
- 独立子图。
- 实际绘图数据CSV。
- 绘图脚本。
- 布局配置。
- 数据来源记录。
- 中英文图注。

所有图中文字、坐标轴、图例和数据标记尽可能保持矢量可编辑。

# 九、最终结果检查及交付

完成三张图后，实际打开生成的图片进行视觉检查。

重点检查：

1. 图片是否能够直接表达对应研究结论。
2. 数值是否与原始实验文件一致。
3. 图表坐标、单位、统计标注是否正确。
4. 是否存在文字重叠、裁剪错误及图例遮挡。
5. 缩小到正式论文宽度后是否仍然可读。
6. F10是否正确区分未评价数据和真实零值。
7. F11是否完整保留两种机制的正负变化。
8. F12是否正确区分关系筛选与实例可用性限制。
9. 三张数据图是否与现有F04—F09保持统一风格。

更新：

- `FIGURE_INDEX.md`
- `docs/GALLERY.md`
- `EXPERIMENT_REPORT.md`
- 已有figure manifest及相关图表索引。

在实验报告中补充对应的数据分析内容，简洁说明每张图的实际结果、研究结论及数据来源。
