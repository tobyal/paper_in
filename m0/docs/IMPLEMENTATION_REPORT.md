## 发现的问题及处理

首次将 SAM 直接加载到 Web 服务线程时，进程在模型加载阶段退出。用户级服务日志确认退出为 `SIGSEGV (11)`，没有证据表明是 GPU OOM。单独主线程推理成功。随后将 SAM 放入独立常驻进程，限制 CPU 数学库线程，并去掉额外注入的动态库路径；真实推理和缓存复测成功。不能把这组同时调整归因于某个唯一库版本问题。

现结构即使模型工作进程异常，HTTP 服务和已提交标注也独立保存；下次推理可重建工作进程。保留 `logs/m0_server_initial_session_failure.log`、`logs/m0_server_systemd.log` 和 `.jobs/sam_worker.log` 供追查。常驻服务独立于 SSH 会话，模型与画布数据都支持重载恢复。

初次选用端口 8766 时发现已被占用，未停止占用者；改为 28760。只操作本项目自己的服务进程。

## 限制与待人工完成事项

- 地面、主通道正方向、坐标原点、2–3 个建模区域和第一批 5–8 个对象仍需标注者依据真实场景确认。自动测试不替代这一工作。
- 真实推车候选的网格空隙、脚轮、深色内部区域及第 66 帧的实例一致性仍需复核；模型高分不能当作掩膜准确率。
- 俯视图使用确定性高斯中心采样、正交投影和相机轨迹。图像拾取点依赖渲染深度/透明度，边界、遮挡或几何误差会影响拟合；人工应选清晰地面并检查多个视角。
- 可选 ROI 是多视角投影交集的粗略范围，尚不处理最终遮挡归属和精确实例提取；不会导出最终高斯 ID 集合。
- 自动同实例重叠提示采用较小掩膜交叠比例 0.35；相机朝向差异小于 10° 时提示视角不足。这些是质量提醒，不是工业识别算法指标。
- 没有开发公网认证、多租户、Grounding DINO、SAM 2 跟踪、外部视觉服务或 M2–M5 正式算法。依赖现有研究环境，不声称已经在任意全新机器验证一键安装。
- 描述 JSON 为候选输入，需人工确认；语义评价没有人工真值，不能报告识别/关系准确率。

交付平台用于继续真实标注。完成确认并冻结首批独立数据后，才进入后续 M1–M5 研究。
